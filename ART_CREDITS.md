### Files and changes

- `assets/cyberpunk-street-ansimuz.png`: the original published PNG preview, without visual edits.
- `assets/cyberpunk-street-ansimuz.gif`: a looping parallax animation assembled from the original far-buildings, back-buildings and foreground layers. The layers move at different speeds; the GIF is palette-encoded. No generative image model was used for these assets.
- The README links to the artist's original work, visibly credits the artist, and provides a static image for reduced-motion preferences.

The previous AI-generated banner has been removed from the current repository files and is no longer used by the profile. It remains in normal Git revision history.
